# dsc180a-steering-llms

DSC 180A (Fall 2026) Quarter 1 project. We replicate [*Emotion Concepts and their Function in a Large Language Model*](https://arxiv.org/abs/2604.07729) (Sofroniew et al., 2026) on open Qwen3 models. For each of 14 emotions, we build a direction ("emotion vector") in the model's residual stream. We will use those vectors for validation, geometry, and steering experiments.

## Setup

Tested with Python 3.12.

```bash
git clone https://github.com/praveendesharma/dsc180a-steering-llms.git
cd dsc180a-steering-llms
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

`requirements.txt` covers `src/` and `notebooks/`. The pipeline notebooks (01 and 03) install their own pinned versions in their first cell (`transformers<5`, `bitsandbytes`), so run them in Colab or in a separate environment.

## Data

| What | Where it comes from |
|---|---|
| **Qwen3-0.6B** (playground) | Downloads from Hugging Face on first run (~1.5 GB) |
| **Qwen3-8B** (pipeline) | Downloads from Hugging Face inside the notebooks; loaded in 4-bit (NF4) |
| **Emotion story dataset** | Committed at `emotion_vector_pipeline/data/qwen3_8b_emotion_stories_1120_v1.zip`, generated by Praveen with Qwen3-8B |
| **Precomputed activations and vectors** | ~1 GB archive on Google Drive. See `emotion_vector_pipeline/README.md` for the link and the folder to extract it into |

The dataset has **1,120 stories: 14 emotions × 20 topics × 4 stories**. Splits are by topic: train = topics 0–13, validation = 14–16, test = 17–19.

To unpack the dataset where notebooks 02 and 03 expect it:

```bash
cd emotion_vector_pipeline
unzip data/qwen3_8b_emotion_stories_1120_v1.zip -d data/generation_v1
cp data/generation_v1/emotion_stories_qwen_full1120.jsonl data/
```

## How to run

**1. Playground (local, a few minutes on a laptop)**

```bash
jupyter notebook notebooks/playground.ipynb   # then Run All
```

Runs on an NVIDIA GPU, Apple Silicon (MPS), or CPU. Expected output: `28 1024`, `torch.Size([1, 14])`, `29`, `torch.Size([1, 14, 1024])`, then a one-sentence reply from the model.

**2. Emotion vector pipeline (in order)**

Open each notebook from inside `emotion_vector_pipeline/`, because its paths are relative to that folder.

| Step | Notebook | Where to run | Notes |
|---|---|---|---|
| 01 | Generate stories | Colab, NVIDIA GPU | Took ~5 hours. **Skip it** and use the committed dataset |
| 02 | Inspect stories | Jupyter or Colab, CPU | Manual quality review; needs `pandas` |
| 03 | Extract vectors | Jupyter or Colab, NVIDIA GPU (a T4 was used) | Writes activations and vectors to `outputs/` |

Notebook 01 saves to Google Drive (Colab only). Notebooks 01 and 03 don't support CPU or Apple MPS. Details: [`emotion_vector_pipeline/README.md`](emotion_vector_pipeline/README.md).
